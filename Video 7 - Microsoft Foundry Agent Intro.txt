### To make your agent access a storage account
	- Create a storage account resource in Azure Portal
	- Click on it and then go to -> access control (IAM)
	- click on Add -> Add role assignment.
	- Type on search bar "Storage Blob Data Contributor"
	- Go to members --> copy the entra agent identity id from foundry -> go back to azure portal -> click on select members -> paste the entra agent identity
	- click "review and assign"
	- Now your agent has access to this storage.
