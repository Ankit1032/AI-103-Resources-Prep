# Azure Basics: Resource Groups and Hubs

An Azure **resource group** is a basic container that holds related cloud items for a solution, a **hub** in networking means a central gateway in a hub-spoke layout, and a **hub** in AI/ML is a shared workspace manager.

---

### Resource Groups
* **Logical container**: Holds items like virtual machines, databases, and storage accounts for a single project.
* **Easy cleanup**: Deleting a resource group deletes everything inside it.
* **Access control**: Applies security policies and role permissions to all inner items at once.

### Hubs in Azure
* **Network Hub**: A central virtual network in a hub-spoke design that manages shared connectivity, firewalls, and routes for different spoke networks.
* **AI/ML Hub**: A workspace manager that shares security, data access, and compute settings across multiple developer project workspaces.
* **Event Hubs**: A big data streaming platform that processes massive volumes of event data from devices and applications.
